## Troubleshooting Common Issues

Install issues? Run setup as administrator and close other video tools that may hold codec files open.  
Performance problems? Set preview to a lower quality, enable hardware decoding, and keep media on the same drive as the project.  
License/activation? Sign in with the account tied to the serial number and re-enter the key if activation expires.  
Compatibility? Install the latest patch when a camera format refuses to import.  
Update failures? Restart, then run the updater from the help menu rather than installing over a running session.
